# Audio file support regressions fixed on 2026-10-21

Each numbered entry describes one independently observable defect. The named regression test failed before its corresponding production change and passes afterwards. Codec spelling variants share an entry.

| # | User trigger | Previous effect | Fix | Regression test |
| --- | --- | --- | --- | --- |
| 1 | Import QuickTime AIFF-C `sowt`/`twos` uncompressed PCM. | Maintained PCM reader rejected the file; browser fallback could not decode otherwise ordinary PCM. | Recognize the integer codec and retain its byte order in the descriptor and chunk reader. | `file-support-aiff-regressions`: QuickTime sowt and twos |
| 2 | Import an AIFF-C `fl64` original. | Double-precision PCM was rejected. | Read big-endian IEEE float64 into the editor's float32 cache, sanitizing nonfinite values. | `file-support-aiff-regressions`: 64-bit AIFF-C |
| 3 | Import an AIFF whose SSND declares storage block alignment and end padding. | A nonzero block size prevented import. | Accept aligned storage, validate bounded end padding, expose only declared sample frames. | `file-support-aiff-regressions`: SSND block alignment |
| 4 | Import 12-bit or 20-bit AIFF integer PCM in whole-byte containers. | Nonbyte precision was rejected. | Select the rounded-up signed sample container and retain the actual precision. | `file-support-aiff-regressions`: integer precision |
| 5 | Import AIFF MARK names containing legacy single-byte accents. | Marker labels contained replacement characters. | Apply the existing AIFF UTF-8/single-byte text policy without trimming label whitespace. | `file-support-aiff-regressions`: legacy AIFF marker |
| 6 | Choose PNG/JPEG cover art from a filesystem that supplies no MIME type or an octet-stream MIME type. | Valid artwork could not be selected. | Identify the supported image format from the file bytes. | `file-support-aiff-regressions`: cover-art files |
| 7 | Import WAV cues with CSET-encoded label or note text. | Labels and notes were always decoded as UTF-8, corrupting accents. | Carry CSET through both the PCM reader and fallback marker scan. | `file-support-riff-regressions`: WAV CSET |
| 8 | Import WAV regions whose descriptions live in the standard ltxt text payload. | Region lengths survived but their names vanished. | Use ltxt text as the label when no labl label is present, respecting its code page. | `file-support-riff-regressions`: region descriptions |
| 9 | Export an album-tagged WAV for a player that reads RIFF INFO. | The album was absent from INFO even though other core fields were written there. | Read and write IPRD as album. | `file-support-riff-regressions`: INFO exports the album |
| 10 | Export metadata containing both a year and a full recording date. | Insertion order could reduce INFO's date to the year. | Prefer the explicit date alias. | `file-support-riff-regressions`: full recording date |
| 11 | Import a big-endian RIFX file through codec fallback. | Cue markers were not scanned at all. | Recognize RIFX and read chunk/cue/region integers in big-endian order. | `file-support-riff-regressions`: RIFX imports |
| 12 | Import a compressed RF64/BW64 original through codec fallback. | The fallback scan ignored its markers. | Walk the ds64 directory and resolve sentinel-sized chunks before scanning cues. | `file-support-riff-regressions`: RF64 compressed imports |
| 13 | Import a WavPack tagged by software that appends ID3v1 after APEv2. | The APE footer was hidden; metadata vanished and the audio decoder received trailer bytes. | Locate APE before the compatibility trailer and strip both before decoding. | `file-support-tag-regressions`: ID3v1 compatibility trailer |
| 14 | Import conventional APE Track, Disc, Year, or Album Artist fields. | Those common field names survived only as raw tags and their standard metadata fields were absent. | Normalize conventional names and separators before mapping them. | `file-support-tag-regressions`: conventional Track, Disc, Year |
| 15 | Import APE track/disc positions formatted as `3/12`. | Numeric coercion produced NaN, so normalized positions were omitted and totals disappeared. | Parse the position and total separately, retaining explicit total fields. | `file-support-tag-regressions`: position/total pairs |
| 16 | Reimport WavPack cover art whose description was exported with the image. | The image survived but the exported description vanished. | Retain the APE image filename/description prefix in the imported artwork descriptor. | `file-support-tag-regressions`: artwork retains its exported description |
| 17 | Export an AAC/M4A with cover art. | Artwork was written both as an image and as base64 JSON in a custom raw tag, inflating files and selecting mdta unnecessarily. | Consume the artwork control field when projecting standard image metadata. | `file-support-tag-regressions`: stored once |
| 18 | In File → Export → AAC, enter supported aliases in Custom Metadata JSON. | Track/disc aliases and differently cased standard fields were emitted only as custom raw tags, invisible to ordinary players. | Project the existing project tag vocabulary to canonical fields before AAC serialization. | `file-support-tag-regressions`: Custom Metadata JSON aliases |
| 19 | Export separate track/disc number and total metadata fields to ID3. | Standard position frames omitted totals; only custom TXXX fields retained them. | Combine separate totals into TRCK/TPOS when the position does not already state a total. | `file-support-tag-regressions`: separate total fields |
| 20 | Import a WAV whose CSET declares a Windows Cyrillic or other maintained legacy code page. | An unsupported-code-page error discarded otherwise readable INFO metadata. | Support browser TextDecoder's Windows, East Asian and ISO legacy code pages. | `file-support-tag-regressions`: Windows Cyrillic |
| 21 | Import a high-rate FLAC with a valid ID3 artwork tag larger than 64 KiB. | An arbitrary prefix cap hid STREAMINFO, preventing the source-rate decode context from being selected. | Skip the declared tag without imposing a smaller artwork limit. | `file-support-rate-regressions`: artwork-sized ID3 prefix |
| 22 | Import a WavPack with a non-table sample rate. | The rate-index escape value returned null instead of reading its mandatory rate metadata. | Walk bounded first-block metadata and decode ID_SAMPLE_RATE. | `file-support-rate-regressions`: nonstandard-rate metadata |
| 23 | Import a free-format MPEG elementary audio file. | A valid free-bitrate index made its known source sample rate appear unknown. | Accept the free-format index while still rejecting the reserved bitrate index. | `file-support-rate-regressions`: free-format MPEG |
| 24 | Import Vorbis audio in an Ogg containing a leading Skeleton logical stream. | The first non-audio page hid the audio's rate declaration. | Walk bounded BOS pages to find the primary audio identification packet. | `file-support-rate-regressions`: Ogg Skeleton |
| 25 | Import an 8-bit AIFF and select Original export. | The shortcut offered an int8 setting the AIFF exporter cannot encode, causing export failure. | Offer original AIFF settings only for sample formats and precisions the exporter represents exactly. | `file-support-aiff-regressions`: 8-bit AIFF originals |
| 26 | Import Ogg-FLAC audio. | The native FLAC rate probe did not recognize its standard Ogg mapping, so the source rate remained unknown. | Read STREAMINFO after the FLAC-to-Ogg identifying header. | `file-support-rate-regressions`: Ogg-FLAC |
| 27 | Import a CRC-protected LAME VBR MP3 and select Original export. | The export settings misidentified the file as constant bitrate because they looked for Xing only after the CRC bytes. | Recognize both encoder layouts for Xing/VBRI and retain LAME's VBR quality. | `file-support-mpeg-regressions`: both CRC-protected Xing layouts |
| 28 | In project Metadata, enter ownership price and purchase date but leave the seller field blank, then export WAV/AIFF/MP3. | Both entered ownership values silently disappeared because OWNE was emitted only for a nonempty seller. | Emit the completed price/date frame with an empty trailing seller string. | `file-support-tag-regressions`: ownership price and purchase date |

The WavPack custom-rate field and Ogg mappings follow the [WavPack format specification](https://www.wavpack.com/WavPack5FileFormat.pdf), [Ogg Skeleton specification](https://xiph.org/ogg/doc/skeleton.html), and [Ogg-FLAC mapping](https://www.xiph.org/flac/ogg_mapping.html).

No compiled/native runtime assets or runtime closure inputs changed. A manual **Update AI assets** run is not required.
