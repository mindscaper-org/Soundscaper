# Native selected Photo Session ownership

The Main-private selected Session lease composes the actual native Catalog,
managed Originals, selected settings, resources, Original transports and binary
derivative cache factories. It is an ownership prerequisite for the complete
Current Session. The complete renderer factory now uses that lease through its
local service contract. The [installed transport](lightscaper-native-photo-session-protocol.md)
now selects this complete factory and its matched restore runtime through the
File menu; Web Core remains the default.

## Selected authority and captured ports

`Scopes.openSessionLease` accepts a genuine current selected scope and a trusted
in-process local retirement owner. Default and allocated restore scopes cannot
grant this role. The manager books one role for the actual selected epoch before
reflecting borrowed options or the local close method. Existing native
components must retire before admission; ordinary component opening stays fenced
throughout the Session role. A second Session refuses before local reflection.
The role survives idle periods and close until physical retirement succeeds.

The opaque one-use lease and exclusive claims bind the actual manager's writer
guard, selected catalog and selection token, epoch and genuine same-generation
components. They are Main-private capabilities, never renderer payloads. The
manager's independent SQLite writer transaction remains the cross-process
exclusion mechanism.

Every exposed method captures its actual receiver. The facades include the
complete Current Catalog/query/stack/saved-collection/backup methods, managed
media and custody, selected settings, retained-Original inspection and repair,
LUT and brush factories, single and group Original transports and binary cache
factories. Escaped resource sources, cache adapters, writers and archive
iterators retain the same local fence. Physical pin allocators, raw body stores,
per-child close and fixed-anchor selection/history authority stay private.
Component-level close delegates to the same cached lease close.

Import presets use a four-method facet over the manager's fixed settings anchor,
restricted to the selected catalog's exact import-preset key. The actual Settings
queue captures native clone and canonical CAS inputs synchronously; selected
admission is checked before SQL and before COMMIT. Reads and false CAS results
recheck the epoch. A true native CAS acknowledgment survives later cancellation
or closure. Generic settings retain their existing structured-clone and
canonical JSON CAS contracts.

The explicit native exclusive callback lane consumes its own one-use purpose
from the selected claim. It rejects overlap and reentry rather than queueing
behind itself, never runs on the manager's serial queue, and joins the actual
callback and listener retirement. A successful callback owns its acknowledgment;
there is no after-callback cancellation check that retracts a durable result.

## Local retirement before physical shutdown

Control cancellation and physical Original-ticket cancellation have separate
signals. Stop fences new selected calls and signals local consumers. It also
starts real escaped-writer/cache producer quiescence: an idle upload writer must
not block an accepted operation that local close is trying to join. Producer
quiescence leaves Original reader pins, tickets and SQLite owners live.

Lease close is cached before cancellation dispatch. It joins captured local
retirement, native exclusive callbacks, import-preset work and producer
quiescence. It then joins accepted native calls and factories, retires escaped
writers and archive iterators, and drains owners registered by those actual
factories. Successful writer commit/abort and archive verify/return unregister
terminal owners promptly; natural archive stream end retains final verification
authority. Failed or pending owners remain registered.

Only after those barriers succeed may physical Components close retire tickets,
Original readers and dependent databases. The manager then closes its remaining
components, registry and fixed anchor, with the writer guard last. Selected
transition uses the same lease close before physical epoch cancellation.
Failed local or physical retirement quarantines the real manager and guard and
retains the owners; neither a timer nor a caller-shaped acknowledgment releases
exclusion.

`createDesktopPhotoLibrarySessionCurrentV1` constructs the actual complete
Current Session, retaining its prototype, strict legacy children, Current
Develop processes, handoff and backup capabilities. It supplies the genuine
Original source, retained-body inspection and repair, native resource and
settings ports, explicit exclusivity, and all three real preview cache adapters.
Browser import preparation, RAW workers and preview decoding stay in the
renderer. Startup reads import intent through its bounded native domain reader;
occupied corrupt rows and insertion-order-sensitive recovery CAS remain intact.

The factory captures actual inner Current Session close as local retirement.
Its `closeResources` retires renderer-local consumers only; the public outer
Session close delegates to the native lease. Pending construction is registered
before entering the actual constructor. Public Close synchronously starts inner
retirement before dispatching cancellation, fencing accepted work while held
consumers drain. Construction failure joins the real inner Session and Original
source without waiting on the remote admission that may itself await local
close. Production transport must own that barrier and actual renderer-process
loss; an arbitrary IPC reply cannot certify consumer retirement.

## Focused evidence

Actual file-backed SQLite and native body tests cover selected admission,
reentrant option/method capture, fixed-anchor CAS, durable acknowledgments,
exclusive callbacks, held single/group Original Files and FileHandle reads,
LUT/brush consumer retirement and wiping, idle writer cancellation, Current ZIP
backup cancellation, terminal owner release and convergent user/manager close.
A separate real process proves failed local cleanup retains exclusion until the
owning process has actually exited. Complete Session integration also covers
both query versions, stacks, saved queries, all culling contexts, metadata and
import-preset persistence, authenticated group/resource ZIP output, physical
repair and reopen, actual HDR decoding and all three persistent preview cache
adapters. These checks do not establish production IPC or menu activation.
