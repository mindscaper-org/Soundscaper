Bewahren Sie vor einem anderen Bearbeitungsversuch eine benannte Arrangement-Version auf.

## Vor dem Start

Öffnen Sie ein beschreibbares Soundscaper-Projekt mit dem Audio, das Sie behalten möchten. Eine Momentaufnahme gehört zu diesem Projekt; speichern Sie zusätzlich eine portable Projektdatei als separate Sicherung.

## Schritte

1. Öffnen Sie **Datei > Session snapshots**.
2. Geben Sie einen **Snapshot name** ein, zum Beispiel „Vor Dialogschnitten“, und wählen Sie **Create snapshot**. Schließen Sie den Dialog und nehmen Sie Ihre Änderungen vor.
3. Um zu dieser Version zurückzukehren, öffnen Sie den Dialog erneut, wählen sie unter **Saved snapshots** aus und wählen **Restore snapshot**.
4. Mit **Rename snapshot** können Sie eine Version genauer bezeichnen; mit **Delete snapshot** entfernen Sie eine nicht mehr benötigte Version.

## Ergebnis prüfen

Das frühere Arrangement und das darin enthaltene Audio werden wiederhergestellt. Schließen Sie den Dialog und spielen Sie den wiederhergestellten Abschnitt ab. **Rückgängig** macht die Wiederherstellung rückgängig, **Wiederherstellen** stellt sie erneut her.

## Grenzen und Wiederherstellung

Eine Momentaufnahme ist ein benannter Projektzustand, keine externe Sicherung. Sie kann Audio enthalten, das aus dem aktuellen Arrangement entfernt wurde, und benötigt daher Speicherplatz. Beim Löschen einer Momentaufnahme bleibt das aktuelle Arrangement erhalten. Siehe [Projektsicherungen](/projects-and-data/storage-backups-and-privacy/).
