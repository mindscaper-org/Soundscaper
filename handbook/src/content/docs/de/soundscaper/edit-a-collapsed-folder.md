Schneiden Sie einen Abschnitt über die verschachtelten Spuren eines Ordners hinweg oder fügen Sie ihn ein, ohne alle Spuren auszuklappen.

## Vor dem Start

Erstellen Sie einen Spurordner mit **Spurmenü > Auswahl in neuen Ordner verschieben**, oder öffnen Sie ein vorhandenes Ordner-Arrangement. Bestimmen Sie den Ordner, dessen Inhalte gemeinsam verschoben werden sollen.

## Schritte

1. Wählen Sie den eingeklappten Ordner und dann **Bearbeiten > Edit folder contents > Select folder contents**. Dasselbe Untermenü gibt es im Kontextmenü des Ordners.
2. Ziehen Sie im Ordnerüberblick einen Zeitbereich auf und prüfen Sie Beginn und Ende der Auswahl.
3. Wählen Sie unter **Cut from folder and close gap** die Option **Edit folder contents**, um den Abschnitt zu entfernen und späteres Material innerhalb dieses Ordners nach vorne zu verschieben.
4. Mit **Insert clipboard into folder** fügen Sie kopiertes Material ein; **Rückgängig** macht den Vorgang rückgängig.

## Ergebnis prüfen

Der Ordner bleibt eingeklappt, während die untergeordneten Spuren bearbeitet werden. Klappen Sie ihn anschließend auf, prüfen Sie die Schnitte und vergewissern Sie sich, dass Spuren außerhalb des Ordners unverändert sind.

## Grenzen und Wiederherstellung

Ordnerbearbeitungen gelten für die untergeordneten Spuren und nicht automatisch für das ganze Projekt. Hören Sie den Übergang mit Musik oder Atmosphäre außerhalb des Ordners ab, um unbeabsichtigte Timing-Unterschiede zu erkennen. Prüfen Sie Sperren und Ordner, bevor Sie eine gruppierte Bearbeitung ausführen. Speichern Sie vor größeren strukturellen Änderungen eine [Momentaufnahme](/soundscaper/save-session-snapshots/).
