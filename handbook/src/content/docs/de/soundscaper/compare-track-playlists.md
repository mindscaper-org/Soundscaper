Bewahren Sie mehrere Arrangements derselben Spur auf und wechseln Sie zwischen ihnen.

## Vor dem Start

Wählen Sie in einem beschreibbaren Soundscaper-Projekt die zu bearbeitende Audiospur aus. Wiedergabelisten schalten das Material dieser Spur um; mit einer [Sitzungs-Momentaufnahme](/soundscaper/save-session-snapshots/) sichern Sie ein ganzes Arrangement.

## Schritte

1. Öffnen Sie **Spuren > Track playlists**.
2. Geben Sie einen **Playlist name** ein und wählen Sie **Duplicate current playlist**. Bearbeiten Sie diese aktive Kopie auf der Zeitleiste. Wenn Sie eine leere Version benötigen, wählen Sie stattdessen **Create empty playlist**.
3. Öffnen Sie den Dialog erneut, wählen Sie unter **Original** den Eintrag **Playlists** und dann **Activate playlist**, um die frühere Bearbeitung anzuhören.
4. Aktivieren Sie die alternative Version, um sie zu vergleichen. Benennen Sie sie mit **Rename playlist** um oder löschen Sie eine inaktive Wiedergabeliste, wenn Sie fertig sind.

## Ergebnis prüfen

Auf der Spur ist nur die aktive Wiedergabeliste zu sehen. **Rückgängig** macht einen Wechsel rückgängig. Warten Sie, bis das Projekt gespeichert wurde, öffnen Sie es erneut und prüfen Sie, ob beide benannten Versionen noch verfügbar sind.

## Grenzen und Wiederherstellung

Die aktive Wiedergabeliste kann nicht gelöscht werden. Inaktive Versionen behalten referenziertes Audio und benötigen Speicherplatz. Wiedergabelisten sind Alternativen auf einer Spur, keine gleichzeitigen Ebenen. Legen Sie Material auf getrennte Spuren, wenn Sie beides zugleich hören möchten.
