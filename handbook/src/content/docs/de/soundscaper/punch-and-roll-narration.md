Hören Sie vor der Aufnahme einen kurzen Vorlauf und wiederholen Sie eine Aufnahme schnell.

## Vor dem Start

Schließen Sie Ihr Mikrofon an und prüfen Sie die [Aufnahmeeinrichtung](/soundscaper/recording/). Verwenden Sie Kopfhörer, damit der Vorlauf nicht ins Mikrofon gelangt. Speichern Sie eine Momentaufnahme, bevor Sie eine wichtige Sprachaufnahme ersetzen.

## Schritte

1. Legen Sie mit Ihrem üblichen Aufnahmeablauf die gewünschte Aufnahmeposition und das Ziel fest.
2. Öffnen Sie das Menü **Record options** der Schaltfläche Aufnahme. Aktivieren Sie **Einzählzeit** und öffnen Sie **Lead-in time settings**, um die **Lead-in duration** festzulegen.
3. Schließen Sie die Einstellungen und starten Sie die Aufnahme. Hören Sie den Vorlauf und sprechen Sie, sobald die Aufnahme die Einsatzposition erreicht.
4. Ist die Aufnahme misslungen, öffnen Sie **Record options** erneut und wählen **Punch again**. Stoppen Sie, wenn Sie zufrieden sind.

## Ergebnis prüfen

Hören Sie den Einsatzpunkt und die aufgenommene Phrase ab. Der neue Versuch sollte dieselbe Einsatzposition und den eingestellten Vorlauf verwenden. Mit **Rückgängig** kehren Sie zur vorherigen Bearbeitung zurück.

## Grenzen und Wiederherstellung

Der Vorlauf ist optional und die Einstellung bleibt erhalten. **Punch again** benötigt einen geeigneten vorherigen Aufnahmeversuch und ist vorher deaktiviert. Stoppen Sie die Aufnahme, bevor Sie die Dauer ändern. Prüfen Sie vor dem erneuten Versuch das tatsächliche Aufnahmeziel, damit Sie den vorgesehenen Abschnitt ersetzen.
