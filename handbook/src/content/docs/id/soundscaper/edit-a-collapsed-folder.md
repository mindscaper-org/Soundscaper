Potong atau sisipkan bagian di trek bersarang dalam folder tanpa membuka setiap trek.

## Sebelum memulai

Buat folder trek dengan **Menu trek > Pindahkan pilihan ke folder baru** pada sebuah trek, atau buka susunan folder yang sudah ada. Tentukan folder yang isinya harus dipindahkan bersama.

## Langkah-langkah

1. Pilih folder yang diciutkan dan pilih **Sunting > Edit folder contents > Select folder contents**. Submenu yang sama tersedia dari menu konteks folder.
2. Seret rentang waktu di ikhtisar folder dan periksa awal serta akhir pilihan.
3. Pilih **Cut from folder and close gap** dari **Edit folder contents** untuk menghapus bagian tersebut dan menggeser materi berikutnya di dalam folder.
4. Gunakan **Insert clipboard into folder** untuk menyisipkan materi yang disalin, atau **Urungkan** untuk membatalkan operasi.

## Periksa hasilnya

Folder tetap diciutkan sementara trek turunannya menerima edit. Buka folder setelah itu untuk memeriksa potongan dan memastikan trek lain di luar folder tidak berubah.

## Batasan dan pemulihan

Edit folder hanya berlaku untuk turunannya, bukan otomatis ke seluruh proyek. Dengarkan bagian edit bersama musik atau suasana di luar folder untuk mengetahui perbedaan waktu yang disengaja. Periksa kunci dan folder yang dimaksud sebelum menerapkan edit berkelompok; simpan [snapshot](/soundscaper/save-session-snapshots/) sebelum perubahan struktur besar.
