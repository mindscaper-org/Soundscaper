Keep multiple arrangements of the same track and switch between them.

## Before you start

Select the audio track you want to edit in a writable Soundscaper project. Playlists switch that track’s material; use a [session snapshot](/soundscaper/save-session-snapshots/) to preserve a whole arrangement.

## Steps

1. Open **Tracks > Track playlists**.
2. Enter a **Playlist name** and choose **Duplicate current playlist**. Edit this active copy on the timeline. Choose **Create empty playlist** instead if you need a blank version.
3. Reopen the dialog, select **Original** under **Playlists**, and choose **Activate playlist** to hear the earlier edit.
4. Activate the alternate version to compare it. Use **Rename playlist** or delete an inactive playlist when finished.

## Check the result

Only the active playlist appears on that track. **Undo** reverses a switch. Wait for the project to save, reopen it, and confirm that both named versions remain available.

## Limits and recovery

The active playlist cannot be deleted. Inactive versions retain their referenced audio and consume storage. Playlists are alternatives on one track, not simultaneous layers; put material on separate tracks to hear both together.
