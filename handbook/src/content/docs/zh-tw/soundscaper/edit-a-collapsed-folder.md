不必展開每條音軌，就能剪下或插入收合資料夾中巢狀音軌的片段。

## 開始之前

在音軌上使用 **軌道選單 > 將選取範圍移入新資料夾** 建立音軌資料夾，或開啟現有的資料夾編排。確認要一起移動內容的資料夾。

## 步驟

1. 選取已收合的資料夾，然後選擇 **編輯 > Edit folder contents > Select folder contents**。資料夾的快顯功能表也有相同的子功能表。
2. 在資料夾概覽中拖曳時間範圍，並檢查選取範圍的起點和終點。
3. 從 **Edit folder contents** 選擇 **Cut from folder and close gap**，即可移除該片段，並將資料夾內後續素材往前移以填補空隙。
4. 使用 **Insert clipboard into folder** 插入已複製素材，或使用 **復原** 復原操作。

## 檢查結果

資料夾維持收合，編輯則套用到其子音軌。之後展開資料夾檢查剪輯，並確認資料夾外無關的音軌仍在原位。

## 限制與復原

資料夾編輯只適用於子音軌，不會自動套用至整個專案。將編輯點與資料夾外的音樂或環境音一起聆聽，以確認是否有預期中的時間差。套用群組編輯前，檢查鎖定狀態和目標資料夾；大幅變更結構前請儲存[快照](/soundscaper/save-session-snapshots/)。
