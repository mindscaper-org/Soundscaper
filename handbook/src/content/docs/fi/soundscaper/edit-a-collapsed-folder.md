Leikkaa tai lisää kohta kansion sisäkkäisille raidoille avaamatta jokaista raitaa.

## Ennen aloitusta

Luo kansioraita valitsemalla **Raidan valikko > Siirrä valinta uuteen kansioon** tai avaa olemassa oleva kansiorakenne. Tunnista kansio, jonka sisällön haluat siirtyvän yhdessä.

## Vaiheet

1. Valitse supistettu kansio ja valitse **Muokkaa > Edit folder contents > Select folder contents**. Sama alivalikko löytyy kansion pikavalikosta.
2. Vedä aikaväli kansion yleisnäkymässä ja tarkista valinnan alku ja loppu.
3. Valitse **Cut from folder and close gap** kohdasta **Edit folder contents** poistaaksesi kohdan ja siirtääksesi myöhemmän materiaalin eteenpäin kansion sisällä.
4. Lisää kopioitu materiaali valinnalla **Insert clipboard into folder** tai peruuta toiminto valinnalla **Kumoa**.

## Tuloksen tarkistaminen

Kansio pysyy supistettuna, kun sen aliraitoja muokataan. Laajenna kansio ja tarkista leikkaukset sekä se, että kansion ulkopuoliset raidat pysyivät paikallaan.

## Rajoitukset ja palautus

Kansiomuokkaukset kohdistuvat aliraitoihin, eivät automaattisesti koko projektiin. Kuuntele muokkausta yhdessä ulkopuolisen musiikin tai tunnelmaäänen kanssa ja havaitse tahattomat ajoituserot. Tarkista lukitukset ja oikea kansio ennen ryhmämuokkausta. Tallenna [tilannevedos](/soundscaper/save-session-snapshots/) ennen suurta rakennemuutosta.
