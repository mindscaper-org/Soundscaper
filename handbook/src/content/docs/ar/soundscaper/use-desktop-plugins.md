اعثر على المؤثرات والآلات الأصلية في Soundscaper لسطح المكتب وفعّلها واستمع إليها.

## قبل البدء

ثبّت إصدار إضافة متوافقًا مع نظام التشغيل لديك وتنسيق المضيف المدعوم. تتوفر إضافات سطح المكتب المضمّنة افتراضيًا في الحزم المدعومة؛ وتتطلب الإضافات الإضافية اكتشافها وقد تحتاج إلى إذن.

## الخطوات

1. افتح **التأثير > إدارة المكونات الإضافية**. ابحث في القائمة واستخدم **الفحص والإعدادات** لإعداد الاكتشاف.
2. حدد الإضافة وراجع إصدارها وأذوناتها وعناصر التحكم في الاسترداد. فعّلها عند ملاءمة ذلك.
3. أضف مؤثرًا عبر **التأثير > تأثيرات المكونات الإضافية الصوتية** أو حاوية فورية. حدد الآلات الأصلية عبر عناصر التحكم الخاصة بالآلة في مسار MIDI.
4. استمع إلى التشغيل، واحفظ إعدادًا مسبقًا إن كان مفيدًا، ثم احفظ المشروع.

## التحقق من النتيجة

ينبغي أن تعالج الإضافة المقصودة الصوت وتعيد تحميل إعداداتها المحفوظة عند توفر الملف الثنائي المتوافق نفسه. تجاوزها للمقارنة وتحقق من التصدير قبل التسليم.

## الحدود والاسترداد

تدعم حزم Windows مسارات الجسر VST2 المصانة، بما في ذلك إضافات 32 بت المدعومة. يمكن لنظام Linux استخدام Windows VST3 عبر إعداد yabridge/Wine مثبّت ومهيأ؛ لكنه لا يثبّت إضافات الجهات الخارجية ولا يمنح تراخيصها. لا تتضمن الإعدادات المسبقة الملفات الثنائية. إذا تعطلت إضافة، فاستخدم عناصر الاسترداد في Plugin Manager وجرب إصدارًا متوافقًا قبل استئناف العمل.
