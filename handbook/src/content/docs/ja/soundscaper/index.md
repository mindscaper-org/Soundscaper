Soundscaper は音声を中心としたエディターです。Audacity に沿ったメニューと編集モデル、プロジェクトビン、非破壊のマルチトラック配置、録音、リアルタイムエフェクト、ラウドネスと周波数の分析、ポータブルなプロジェクト交換を組み合わせています。

## おすすめの進め方

1. チュートリアル[最初の Soundscaper プロジェクト](/tutorials/your-first-project/)を進めます。
2. 新しい素材が必要なら[録音を設定](/soundscaper/recording/)します。
3. [編集、ミックス、書き出し](/soundscaper/edit-mix-and-export/)を行います。
4. [保存とバックアップの動作](/projects-and-data/storage-backups-and-privacy/)を確認します。
5. ノイズ除去、フェード、ラウドネス、書き出しなど、今の作業に合った[操作ガイド](/guides/)を選びます。

ブラウザーエディターは[soundscaper.org/en](https://soundscaper.org/en/)で開きます。

デスクトップでの支援については[ローカル処理、モデル、プラグイン](/help/local-processing/)を参照してください。

別のトランスポートに追従または同期するには[タイムコード同期](/soundscaper/timecode-synchronization/)を参照してください。
