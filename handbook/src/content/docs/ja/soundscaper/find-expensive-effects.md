処理を簡素化する前に、リアルタイムエフェクトの負荷を比較します。

## 始める前に

リアルタイムエフェクトと、負荷の高い代表的な箇所を含むプロジェクトを使います。測定結果はこのデバイスと作業負荷についてのもので、プラグイン全般に当てはまる順位ではありません。

## 手順

1. **ヘルプ > CPU profiling** を開きます。
2. パネルを開いた後に再生を開始またはやり直し、各リアルタイムエフェクトを測定します。
3. 数回の更新を確認します。エフェクトの行と基本エディターの行を比較し、負荷の高いエフェクトを1つバイパスして同じ箇所を再生します。
4. 終わったらパネルを閉じ、保持する処理を戻します。

## 結果を確認する

CPU 使用率は1コアの容量を超える場合があります。100% は CPU 1コアを完全に使用していることを示します。CPU の割合と経過処理時間の割合を比べます。ダッシュは測定値がないことを示し、負荷がゼロという意味ではありません。

## 制限と復旧

経過処理時間にはスケジューリングの遅延が含まれます。GPU の使用量と外部ヘルパープロセスは除外され、プロファイリング自体にも負荷があります。バイパスしたエフェクトは別に表示されます。無音時に適切なプロセッサーを休止させるには、エフェクトヘッダーの **その他のオプション > Auto-idle** を開きます。連続したタイミングが必要なエフェクトでは無効にしてください。関連設定は[ローカル処理](/help/local-processing/)を参照してください。変更を比較するときは、必ず同じ箇所を再生します。
