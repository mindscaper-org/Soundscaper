対応するオーディオ編集を読み込み、メディアを再接続し、変換の制限を確認します。

## 始める前に

セッションと音声をアクセス可能なフォルダーにコピーします。対応するネイティブオーディオセッションは REAPER `.rpp`、Hindenburg `.nhsx`、Pro Tools `.pts`/`.ptf`/`.ptx`、Ardour `.ardour`、SoundCraft セッション、Audition `.sesx` または旧形式の `.ses` です。元のプロジェクトも残してください。

## 手順

1. **ファイル > 開く** または **ファイル > インポート** を選ぶか、セッションをワークスペースにドロップします。
2. ブラウザーではセッションに付属する音声を選択します。デスクトップでは、要求されたらメディアフォルダーへのアクセスを許可します。
3. **ファイル > 配信レポート** を開きます。省略や変換の項目を確認し、必要に応じてオフラインメディアを再リンクします。
4. 代表的な編集やフェードを聞き、トラック順とタイミングを確認して、新しい Scape プロジェクトとして保存します。

## 結果を確認する

インポートしたカットはアクセス可能なソース音声と合っているはずです。特に処理、ルーティング、オートメーションが関係する箇所は、元のエディターの基準ミックスと比べます。

## 制限と復旧

ネイティブ読み込みはオーディオ編集の変換であり、ミックスが完全に同じになるとは限りません。対応する詳細は形式によって異なり、ソースセッションのプラグインは実行されません。REAPER ではアクティブなオーディオテイクを使い、別テイクの編集、MIDI、ルーティング、プラグインは省略されます。別の DAW との交換には、ネイティブセッション書き出しを期待せず、AES31 ADL や DAWproject などの対応交換形式を使います。
