Soundscaper デスクトップでネイティブエフェクトや楽器を見つけ、有効にして試聴します。

## 始める前に

OS と対応ホスト形式に互換性のあるプラグインビルドをインストールします。対応パッケージでは同梱デスクトッププラグインが既定で利用できます。追加プラグインは検出が必要で、許可が必要な場合もあります。

## 手順

1. **エフェクト > プラグイン管理** を開きます。リストを検索し、検出設定には **スキャンと設定** を使います。
2. プラグインを選び、バージョン、許可、復旧コントロールを確認します。適切であれば有効にします。
3. **エフェクト > オーディオプラグイン** またはリアルタイムラックからエフェクトを追加します。MIDI トラックの楽器コントロールからネイティブ楽器を選びます。
4. 再生を試聴し、必要ならプリセットを保存してからプロジェクトを保存します。

## 結果を確認する

同じ互換バイナリが利用可能なら、目的のプラグインで音が処理され、保存した設定で再読み込みされます。納品前にバイパスして比較し、書き出しも確認します。

## 制限と復旧

Windows パッケージは、対応する32ビットプラグインを含む、保守対象の VST2 ブリッジ経路をサポートします。Linux ではインストール、設定済みの yabridge/Wine を通じて Windows VST3 を使用できますが、サードパーティ製プラグインのインストールやライセンスが提供されるわけではありません。プラグインのプリセットにバイナリは含まれません。プラグインが失敗した場合は Plugin Manager の復旧コントロールを使い、作業を再開する前に互換バージョンを試します。
