Soundscaper 데스크톱에서 네이티브 효과와 악기를 찾아 활성화하고 들어봅니다.

## 시작하기 전에

운영 체제와 지원 호스트 형식에 호환되는 플러그인 빌드를 설치합니다. 지원되는 패키지에서는 번들 데스크톱 플러그인이 기본으로 제공됩니다. 추가 플러그인은 검색해야 하며 필요한 권한이 있을 수 있습니다.

## 단계

1. **이펙트 > 플러그인 관리자**를 엽니다. 목록을 검색하고 **스캔 및 설정**에서 검색 설정을 지정합니다.
2. 플러그인을 선택하고 버전, 권한, 복구 컨트롤을 확인합니다. 적절하면 활성화합니다.
3. **이펙트 > 오디오 플러그인**나 실시간 랙에서 효과를 추가합니다. MIDI 트랙의 악기 컨트롤로 네이티브 악기를 선택합니다.
4. 재생을 들어보고 필요하면 프리셋을 저장한 다음 프로젝트를 저장합니다.

## 기타 앰프로 연주하기

**이펙트 > 오디오 플러그인** 또는 트랙의 실시간 이펙트 랙에서 **OrbitAmp**를 추가합니다. 플러그인 편집기를 열고 **AMP** 섹션에서 앰프를, **CAB** 섹션에서 스피커 캐비닛을 선택합니다. 데스크톱 패키지에는 팩토리 사운드가 포함되어 있습니다.

## 결과 확인

호환되는 동일한 바이너리를 사용할 수 있으면 선택한 플러그인이 소리를 처리하고 저장한 설정으로 다시 로드되어야 합니다. 전달 전에 우회해 비교하고 내보내기를 확인합니다.

## 제한 및 복구

Windows 패키지는 지원되는 32비트 플러그인을 포함해 유지 관리되는 VST2 브리지 경로를 지원합니다. Linux는 설치되고 구성된 yabridge/Wine 환경에서 Windows VST3를 사용할 수 있습니다. 이 기능이 타사 플러그인을 대신 설치하거나 라이선스하는 것은 아닙니다. 플러그인 프리셋에는 바이너리가 포함되지 않습니다. 플러그인에 문제가 있으면 Plugin Manager의 복구 컨트롤을 사용하고 호환 버전을 시험한 뒤 작업을 재개합니다.
