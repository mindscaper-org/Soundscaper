시간이 지정된 트랜스크립트에서 단어를 선택해 이동하고 오디오를 편집합니다.

## 시작하기 전에

말소리가 포함된 프로젝트를 엽니다. 새 트랜스크립트를 생성하려면 데스크톱 앱, 호환되는 로컬 모델의 설치, 명시적인 동의가 필요합니다. 기존에 시간이 지정된 트랜스크립트는 다시 생성하지 않고 사용할 수 있습니다.

## 단계

1. **편집 > Transcript-based editing**을 엽니다.
2. 사용할 수 있다면 **Generate transcript**를 선택하고 모델 및 권한 안내를 따릅니다. 오디오 트랙의 처리가 끝날 때까지 기다립니다.
3. 단어를 클릭하면 해당 오디오로 이동합니다. 단어를 두 번 클릭해 선택한 다음 타임라인에서 강조된 범위를 확인합니다.
4. 트랜스크립트에 포커스가 있을 때 **Backspace** 또는 **삭제**를 눌러 선택한 단어와 연결된 오디오를 제거합니다. 편집 지점의 연결을 듣고 필요하면 **되돌리기**를 사용합니다.

## 결과 확인

트랜스크립트와 오디오가 함께 편집되고 확대율을 바꾸지 않아도 선택 구간이 보입니다. 저장한 뒤 패널을 닫고 다시 열어 보존된 트랜스크립트로 작업을 이어갑니다.

## 제한 및 복구

음성 인식과 단어 타이밍은 틀릴 수 있으니 삭제 전에 들어보세요. 웹 편집기는 생성 기능이 데스크톱 전용이라고 안내하며 모델을 다운로드하거나 실행하지 않습니다. 트랜스크립트는 편집 보조 자료이지, 정확한 축어 기록을 보장하지 않습니다. 대화 구간을 크게 편집하기 전에 [스냅샷](/soundscaper/save-session-snapshots/)을 보존합니다.
