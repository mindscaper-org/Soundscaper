Analysis 패널에서 실시간 스펙트럼, 음량, 스테레오 검사, ACX 오디오 보고서를 확인합니다.

## 시작하기 전에

오디오가 있는 프로젝트를 엽니다. 재생 중인 오디오와 선택한 범위 중 무엇을 확인할지 정합니다. 시간 선택 영역이 있으면 스펙트럼이 선택 영역 분석으로 전환될 수 있습니다.

## 단계

1. **분석 > 분석**를 엽니다. **Spectrum**, 스펙트로그램, 음량, 상관관계 등 필요한 섹션을 펼칩니다.
2. 시간 선택 영역을 지우고 재생을 시작해 실시간 화면을 확인합니다. 스펙트럼에서 트랙 오버레이를 비교해 서로 경쟁하는 주파수 대역을 찾습니다.
3. 재생을 멈추고 구간을 선택하면 재생 없이 스펙트럼을 살펴볼 수 있습니다.
4. 오디오북을 점검하려면 **ACX compliance**를 펼치고 **Check audio**를 선택합니다. 결과 표를 확인하고 JSON 보고서는 **내보내기**를 사용합니다.

## 결과 확인

실시간 표시가 재생에 반응합니다. ACX 보고서는 미터만 보여주는 것이 아니라 오디오 검사별 통과 또는 실패를 표시합니다. 실패한 음량이나 형식 설정을 수정하고 다시 확인합니다.

## 제한 및 복구

스펙트럼은 에너지를 표시할 뿐 믹스가 좋은지 알려주지 않습니다. 상관관계와 음량은 맥락과 청취가 필요합니다. ACX 오디오 검사는 출판 서비스의 승인을 보장하지 않으며 모든 편집 요구 사항도 확인하지 않습니다. ACX 섹션을 접으면 표시된 검사 결과가 지워집니다. 필요하면 다시 실행하세요. 불필요한 분석기 섹션은 닫아 표시 작업을 줄입니다.
