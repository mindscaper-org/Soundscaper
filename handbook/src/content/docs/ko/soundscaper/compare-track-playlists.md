같은 트랙의 여러 편곡을 보관하고 서로 전환합니다.

## 시작하기 전에

쓰기 가능한 Soundscaper 프로젝트에서 편집할 오디오 트랙을 선택합니다. 플레이리스트는 해당 트랙의 자료를 전환합니다. 전체 편곡을 보존하려면 [세션 스냅샷](/soundscaper/save-session-snapshots/)을 사용하세요.

## 단계

1. **트랙 메뉴 > Track playlists**를 엽니다.
2. **Playlist name**을 입력하고 **Duplicate current playlist**를 선택합니다. 타임라인에서 활성 복사본을 편집합니다. 빈 버전이 필요하면 **Create empty playlist**를 선택하세요.
3. 대화상자를 다시 열고 **Playlists**에서 **원본**을 선택한 다음 **Activate playlist**를 선택해 이전 편집을 들어봅니다.
4. 대체 버전을 활성화해 비교합니다. 완료하면 **Rename playlist**를 사용하거나 비활성 플레이리스트를 삭제합니다.

## 결과 확인

해당 트랙에는 활성 플레이리스트만 표시됩니다. **되돌리기**로 전환을 되돌릴 수 있습니다. 프로젝트가 저장될 때까지 기다린 후 다시 열어 이름이 지정된 두 버전이 모두 남아 있는지 확인합니다.

## 제한 및 복구

활성 플레이리스트는 삭제할 수 없습니다. 비활성 버전도 참조하는 오디오를 보존하므로 저장 공간을 사용합니다. 플레이리스트는 한 트랙의 대안이지 동시에 재생되는 레이어가 아닙니다. 두 버전을 함께 들으려면 자료를 별도 트랙에 배치하세요.
