리버브나 딜레이 잔향을 반복되는 오디오 파일의 시작 부분으로 접어 넣습니다.

## 시작하기 전에

원하는 처리가 적용된 정확한 루프 범위를 준비합니다. 연결 지점을 확인할 때는 WAV 같은 무손실 형식을 사용합니다. 일반 재생과 내보내기 레벨은 클리핑 아래로 유지합니다.

## 단계

1. 반복할 시간 범위를 선택하고 **파일 > 오디오 내보내기**를 엽니다.
2. 선택한 범위와 적절한 형식, 샘플 레이트, 채널 레이아웃을 지정합니다.
3. 내보내기 설정에서 **Render as loop**를 켭니다. 파일을 내보냅니다.
4. 결과를 테스트 프로젝트로 가져와 여러 번 반복해 듣고 특히 경계 부분을 확인합니다.

## 결과 확인

내보낸 파일은 선택한 루프 길이를 유지하고 렌더된 잔향은 시작 부분으로 접혀 들어갑니다. 클릭음, 음량 상승, 부드러운 리버브 전환을 확인합니다.

## 제한 및 복구

잔향 접기는 부적절한 음악 컷이나 끊긴 드라이 파형을 고칠 수 없습니다. 일반 내보내기를 연장하는 **10초까지 이펙트 테일 포함**와는 다릅니다. 잔향이 합산되면 피크가 높아질 수 있습니다. 레벨을 낮추거나 Limiter의 선택적 트루 피크 리미팅을 사용하고 전달 파일을 확인합니다. 손실 형식은 패딩을 추가하거나 피크를 바꿀 수 있으므로 실제 대상 형식도 확인하세요.
