Συγκρίνετε το κόστος των εφέ πραγματικού χρόνου πριν αποφασίσετε ποια επεξεργασία θα απλοποιήσετε.

## Πριν ξεκινήσετε

Χρησιμοποιήστε έργο με εφέ πραγματικού χρόνου και μια αντιπροσωπευτική απαιτητική παύση. Οι μετρήσεις περιγράφουν τη συγκεκριμένη συσκευή και φόρτο εργασίας· δεν αποτελούν καθολική κατάταξη προσθέτων.

## Βήματα

1. Ανοίξτε **Βοήθεια > CPU profiling**.
2. Αφού ανοίξετε το πλαίσιο, ξεκινήστε ή επανεκκινήστε την αναπαραγωγή ώστε να μετρηθεί κάθε εφέ πραγματικού χρόνου.
3. Παρακολουθήστε αρκετές ενημερώσεις. Συγκρίνετε τις γραμμές εφέ με τη βασική γραμμή του προγράμματος και παρακάμψτε ένα απαιτητικό εφέ πριν επαναλάβετε την ίδια παύση.
4. Κλείστε το πλαίσιο όταν τελειώσετε και επαναφέρετε όποια επεξεργασία θέλετε να κρατήσετε.

## Έλεγχος αποτελέσματος

Η χρήση CPU μπορεί να υπερβεί τη χωρητικότητα ενός πυρήνα: το 100% αντιστοιχεί σε έναν πλήρως απασχολημένο πυρήνα CPU. Συγκρίνετε τα ποσοστά CPU και χρόνου επεξεργασίας. Η παύλα σημαίνει ότι δεν υπάρχει διαθέσιμη μέτρηση, όχι μηδενικό κόστος.

## Όρια και αποκατάσταση

Ο χρόνος επεξεργασίας περιλαμβάνει καθυστερήσεις προγραμματισμού. Η χρήση GPU και οι εξωτερικές βοηθητικές διεργασίες εξαιρούνται, ενώ το ίδιο το profiling προσθέτει επιβάρυνση. Το παρακαμφθέν εφέ επισημαίνεται χωριστά. Ανοίξτε **Περισσότερες επιλογές > Auto-idle** στην κεφαλίδα ενός εφέ, ώστε ένας κατάλληλος επεξεργαστής να αδρανεί κατά τη σιωπή. Απενεργοποιήστε τη λειτουργία για εφέ που χρειάζονται συνεχή χρονισμό. Δείτε τις [ρυθμίσεις τοπικής επεξεργασίας](/help/local-processing/) για σχετικές επιλογές. Όταν συγκρίνετε αλλαγές, αναπαράγετε ξανά την ίδια παύση.
