Před vyzkoušením jiné úpravy si uchovejte pojmenovanou verzi aranžmá.

## Než začnete

Otevřete zapisovatelný projekt Soundscaper se zvukem, který chcete zachovat. Snímek patří do tohoto projektu; samostatnou zálohu vytvoříte také uložením přenositelného souboru projektu.

## Postup

1. Otevřete **Soubor > Session snapshots**.
2. Zadejte **Snapshot name**, například „Před střihy dialogu“, a zvolte **Create snapshot**. Zavřete dialog a proveďte úpravy.
3. Chcete-li se k verzi vrátit, dialog znovu otevřete, vyberte ji v části **Saved snapshots** a zvolte **Restore snapshot**.
4. Pomocí **Rename snapshot** verzi lépe popište, případně zvolte **Delete snapshot**, pokud ji už nepotřebujete.

## Kontrola výsledku

Vrátí se dřívější aranžmá i zvuk, který obsahovalo. Zavřete dialog a přehrajte obnovenou část. **Zpět** obnovu vrátí a **Znovu** ji opět provede.

## Omezení a obnova

Snímek je pojmenovaný stav projektu, nikoli externí záloha. Může uchovávat zvuk odstraněný z aktuálního aranžmá, a proto zabírá místo. Odstraněním snímku se aktuální aranžmá nezmění. Viz [zálohování projektů](/projects-and-data/storage-backups-and-privacy/).
