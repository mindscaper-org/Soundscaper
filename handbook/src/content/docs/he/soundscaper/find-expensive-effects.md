השוו את העלות של אפקטים בזמן אמת לפני שתחליטו איזה עיבוד לפשט.

## לפני שמתחילים

השתמשו בפרויקט עם אפקטים בזמן אמת וקטע עמוס מייצג. המדידות מתארות את המכשיר והעומס האלה; הן אינן דירוג כללי של תוספים.

## שלבים

1. פתחו **עזרה > CPU profiling**.
2. התחילו או הפעילו מחדש את הניגון אחרי פתיחת החלונית כדי למדוד כל אפקט בזמן אמת.
3. עקבו אחר כמה עדכונים. השוו את שורות האפקטים לשורת העורך הבסיסי; עקפו אפקט יקר אחד והשמיעו שוב את אותו קטע.
4. סגרו את החלונית בסיום ושחזרו כל עיבוד שתרצו לשמור.

## בדיקת התוצאה

השימוש ב-CPU עשוי לחרוג מקיבולת ליבה אחת: 100% מייצגים ליבת CPU אחת תפוסה במלואה. השוו את אחוזי ה-CPU ואת זמן העיבוד שחלף. מקף מציין שאין מדידה זמינה, לא שאין עלות.

## מגבלות ושחזור

זמן העיבוד שחלף כולל עיכובי תזמון. שימוש ב-GPU ותהליכי עזר חיצוניים אינם נכללים, והפרופיל עצמו מוסיף תקורה. אפקט שעוקף מזוהה בנפרד. פתחו את **אפשרויות נוספות > Auto-idle** בכותרת האפקט כדי לאפשר למעבד מתאים לישון בזמן שקט. השביתו זאת לאפקטים שדורשים תזמון רציף. ראו [עיבוד מקומי](/help/local-processing/) להגדרות קשורות. השמיעו תמיד את אותו קטע כשמשווים שינויים.
