חתכו או הוסיפו קטע לרצועות מקוננות בתיקייה בלי להרחיב כל רצועה.

## לפני שמתחילים

צרו תיקיית רצועות בעזרת **תפריט מסלול > העברת הבחירה לתיקייה חדשה**, או פתחו מבנה תיקיות קיים. זהו את התיקייה שתכולתה צריכה לזוז יחד.

## שלבים

1. בחרו את התיקייה המכווצת ובחרו **עריכה > Edit folder contents > Select folder contents**. אותה תת-תפריט זמינה גם מתפריט ההקשר של התיקייה.
2. גררו טווח זמן בסקירת התיקייה ובדקו את תחילת הבחירה ואת סופה.
3. בחרו **Cut from folder and close gap** מתוך **Edit folder contents** כדי להסיר את הקטע ולדחוף קדימה חומר מאוחר יותר בתוך התיקייה.
4. השתמשו ב-**Insert clipboard into folder** כדי להוסיף חומר שהועתק, או ב-**ביטול** כדי לבטל את הפעולה.

## בדיקת התוצאה

התיקייה נשארת מכווצת בזמן שהעריכה חלה על רצועות הצאצא שלה. הרחיבו אותה אחר כך כדי לבדוק את החיתוכים ולאשר שרצועות לא קשורות מחוץ לתיקייה נשארו במקומן.

## מגבלות ושחזור

עריכות בתיקייה מוגבלות לצאצאיה ואינן חלות אוטומטית על הפרויקט כולו. האזינו לעריכה יחד עם מוזיקה או אווירה מחוץ לתיקייה כדי לזהות הבדל תזמון לא מכוון. בדקו נעילות ואת התיקייה הנכונה לפני החלת עריכה קבוצתית; שמרו [תמונת מצב](/soundscaper/save-session-snapshots/) לפני שינוי מבני גדול.
