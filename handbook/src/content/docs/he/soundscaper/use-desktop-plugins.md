מצאו, הפעילו והאזינו לאפקטים ולכלים מקוריים ב-Soundscaper לשולחן העבודה.

## לפני שמתחילים

התקינו build של תוסף שתואם למערכת ההפעלה שלכם ולפורמט host נתמך. תוספי שולחן העבודה המצורפים זמינים כברירת מחדל בחבילות נתמכות; תוספים נוספים עדיין דורשים גילוי ואולי הרשאה.

## שלבים

1. פתחו **אפקט > מנהל תוספים**. חפשו ברשימה והשתמשו ב-**סריקה והגדרות** כדי להגדיר גילוי.
2. בחרו את התוסף ובדקו את הגרסה, ההרשאה ואמצעי השחזור שלו. הפעילו אותו כשזה מתאים.
3. הוסיפו אפקט דרך **אפקט > אפקטים של פלאגינים אודיו** או rack בזמן אמת. בחרו כלים מקוריים מתוך פקדי הכלי ברצועת MIDI.
4. האזינו להפעלה, שמרו preset אם הוא שימושי ושמרו את הפרויקט.

## נגינה דרך מגבר גיטרה

הוסיפו את **OrbitAmp** דרך **אפקט > אפקטים של פלאגינים אודיו** או דרך מתקן האפקטים בזמן אמת של הרצועה. פתחו את עורך התוסף ובחרו מגבר במקטע **AMP** ותיבת רמקולים במקטע **CAB**. חבילת שולחן העבודה כוללת את צלילי היצרן.

## בדיקת התוצאה

התוסף המיועד אמור לעבד את הצליל ולטעון מחדש את ההגדרות השמורות כשהבינארי התואם הזהה זמין. עקפו אותו להשוואה ובדקו את הייצוא לפני המסירה.

## מגבלות ושחזור

חבילות Windows תומכות בנתיבי bridge מתוחזקים של VST2, כולל תוספי 32 סיביות נתמכים. Linux יכול להשתמש ב-Windows VST3 דרך תצורת yabridge/Wine מותקנת ומוגדרת; הדבר אינו מתקין או מעניק רישיון לתוספי צד שלישי. Presets אינם כוללים קבצים בינאריים. אם תוסף נכשל, השתמשו בבקרי השחזור של Plugin Manager ונסו גרסה תואמת לפני חידוש העבודה.
