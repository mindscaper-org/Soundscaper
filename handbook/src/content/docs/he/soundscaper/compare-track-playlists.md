שמרו כמה סידורים של אותה רצועה ועברו ביניהם.

## לפני שמתחילים

בחרו את רצועת האודיו שברצונכם לערוך בפרויקט Soundscaper שניתן לכתוב בו. רשימות השמעה מחליפות את החומר ברצועה הזו; השתמשו ב[תמונת מצב של הסשן](/soundscaper/save-session-snapshots/) כדי לשמור סידור שלם.

## שלבים

1. פתחו **רצועות > Track playlists**.
2. הזינו **Playlist name** ובחרו **Duplicate current playlist**. ערכו את העותק הפעיל בציר הזמן. אם דרושה לכם גרסה ריקה, בחרו **Create empty playlist**.
3. פתחו שוב את תיבת הדו-שיח, בחרו **מקור** תחת **Playlists** ובחרו **Activate playlist** כדי לשמוע את העריכה הקודמת.
4. הפעילו את הגרסה החלופית כדי להשוות ביניהן. בסיום השתמשו ב-**Rename playlist** או מחקו רשימת השמעה לא פעילה.

## בדיקת התוצאה

רק רשימת ההשמעה הפעילה מופיעה ברצועה. **ביטול־ביצוע** מבטל מעבר בין גרסאות. המתינו לשמירת הפרויקט, פתחו אותו מחדש ואשרו ששתי הגרסאות בעלות השם עדיין זמינות.

## מגבלות ושחזור

אי אפשר למחוק את רשימת ההשמעה הפעילה. גרסאות לא פעילות שומרות הפניות לאודיו ולכן צורכות שטח אחסון. רשימות השמעה הן חלופות ברצועה אחת ולא שכבות בו-זמניות; הציבו את החומר ברצועות נפרדות כדי לשמוע את שניהם יחד.
