למדו ייחוס גווני והשתמשו ב-Match EQ כדי לקרב אליו הקלטה אחרת.

## לפני שמתחילים

בחרו ייחוס נשמע בטווח תדרים מלא שנמשך לפחות רבע שנייה, רצוי של אותו דובר בהקלטה טובה. הכינו את הקלטת היעד. התכונה משתמשת בעיבוד מקומי בדפדפן ובשולחן העבודה.

## שלבים

1. בחרו את הייחוס ופתחו **אפקט > איקוולייזר ומסננים > Match EQ**. בחרו **Learn reference from selection**.
2. שמרו את הייחוס שנלמד כ-preset אם תרצו להשתמש שוב בפרופיל הקול הזה. סגרו את תיבת הדו-שיח.
3. בחרו את היעד, פתחו שוב את Match EQ, טענו את הייחוס אם צריך ובחרו **Analyze target**.
4. השתמשו ב-**תצוגה מקדימה** כדי להשוות בין **מקור** ל-**Matched (level compensated)**. כווננו את התיקון ואז בחרו **החל על הבחירה** או **Edit as Filter Curve EQ** כדי לערוך את העקומה.

## בדיקת התוצאה

האזינו בעוצמת קול דומה כדי להשוות את האיזון הגווני. האודיו שעובד שומר על משכו ומספר הערוצים שלו. **ביטול־ביצוע** מבטל את ההחלה.

## מגבלות ושחזור

Match EQ אינו יכול לשחזר רוחב פס חסר ואינו מתאים ביצוע, דינמיקה, הד חדר או זהות קולית. הקלטת הייחוס כוללת אפקטים של הרצועה לפני bus-ים והמאסטר; היעד מנותח לפני ה-rack של הרצועה. רנדרו תחילה את הייחוס כאשר הצליל הרצוי תלוי בעיבוד בהמשך השרשרת.
