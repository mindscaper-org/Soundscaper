Soundscaper-ի աշխատասեղանի տարբերակում գտեք, միացրեք և լսեք native էֆեկտներն ու գործիքները։

## Նախքան սկսելը

Տեղադրեք ձեր օպերացիոն համակարգի և աջակցվող host ձևաչափի հետ համատեղելի plug-in-ի build։ Աջակցվող փաթեթներում ներկառուցված աշխատասեղանի plug-in-ները հասանելի են լռելյայն. լրացուցիչ plug-in-ները պետք է հայտնաբերել, և կարող է պահանջվել թույլտվություն։

## Քայլեր

1. Բացեք **Էֆեկտ > Խմբավորումների կառավարիչ**։ Որոնեք ցուցակում և հայտնաբերման կարգավորումների համար օգտագործեք **Փնտրտուք և կարգավորումներ**։
2. Ընտրեք plug-in-ը և ստուգեք դրա տարբերակը, թույլտվությունն ու վերականգնման կառավարիչները։ Միացրեք, եթե տեղին է։
3. Ավելացրեք էֆեկտ **Էֆեկտ > Աուդիո պլագիններ** բաժնից կամ իրական ժամանակի դարակից։ MIDI ուղու գործիքի կառավարիչներով ընտրեք native գործիքները։
4. Լսեք նվագարկումը, անհրաժեշտության դեպքում պահպանեք preset-ը և պահեք նախագիծը։

## Նվագել կիթառի ուժեղացուցիչով

Ավելացրեք **OrbitAmp**-ը **Էֆեկտ > Աուդիո պլագիններ** ցանկից կամ ուղու իրական ժամանակի էֆեկտների դարակից։ Բացեք փլագինի խմբագրիչը և **AMP** բաժնում ընտրեք ուժեղացուցիչ, իսկ **CAB** բաժնում՝ բարձրախոսի պահարան։ Աշխատասեղանի փաթեթը ներառում է գործարանային հնչյունները։

## Ստուգեք արդյունքը

Նախատեսված plug-in-ը պետք է մշակի ձայնը և համատեղելի նույն binary-ի առկայության դեպքում վերաբեռնվի պահպանված կարգավորումներով։ Հանձնելուց առաջ շրջանցեք համեմատության համար և ստուգեք արտահանումը։

## Սահմանափակումներ և վերականգնում

Windows փաթեթներն աջակցում են պահպանվող VST2 կամրջման ուղիներին, ներառյալ աջակցվող 32-բիթանոց plug-in-ները։ Linux-ը կարող է օգտագործել Windows VST3՝ տեղադրված և կարգավորված yabridge/Wine-ի միջոցով. սա չի տեղադրում կամ լիցենզավորում երրորդ կողմի plug-in-ները։ Plug-in-ի preset-ները չեն ներառում binary-ները։ Եթե plug-in-ը չի աշխատում, օգտագործեք Plugin Manager-ի վերականգնման կառավարիչները և աշխատանքի վերսկսումից առաջ փորձեք համատեղելի տարբերակ։
