Կտրեք կամ տեղադրեք հատված փակված թղթապանակի nested ուղիների վրա՝ առանց ամեն ուղին ընդարձակելու։

## Նախքան սկսելը

Ստեղծեք ուղիների թղթապանակ՝ ուղու **Թրեքի ընտրացանկ > Տեղափոխել ընտրությունը նոր պանակի մեջ** հրամանով կամ բացեք գոյություն ունեցող թղթապանակի դասավորությունը։ Որոշեք, թե որ թղթապանակի բովանդակությունը պետք է շարժվի միասին։

## Քայլեր

1. Ընտրեք փակված թղթապանակը և ընտրեք **Խմբագրել > Edit folder contents > Select folder contents**։ Նույն ենթամենյուն հասանելի է թղթապանակի համատեքստային ընտրացանկից։
2. Թղթապանակի ակնարկում քաշեք ժամանակային տիրույթ և ստուգեք ընտրության սկիզբն ու վերջը։
3. **Edit folder contents** բաժնից ընտրեք **Cut from folder and close gap**՝ հատվածը հեռացնելու և թղթապանակի ներսի հետագա նյութը տեղափոխելու համար։
4. Պատճենված նյութ տեղադրելու համար օգտագործեք **Insert clipboard into folder**, գործողությունը հետ շրջելու համար՝ **Հետարկել**։

## Ստուգեք արդյունքը

Թղթապանակը մնում է փակված, մինչ դրա descendant ուղիները ստանում են խմբագրումը։ Հետագայում բացեք այն՝ կտրվածքները ստուգելու և համոզվելու համար, որ դրսի անկապ ուղիները տեղում են։

## Սահմանափակումներ և վերականգնում

Թղթապանակի խմբագրումները տարածվում են descendant-ների վրա, ոչ թե ինքնաբերաբար ամբողջ նախագծի։ Լսեք խմբագրումը դրսի երաժշտության կամ միջավայրային ձայնի հետ՝ դիտավորյալ ժամանակային տարբերությունը նկատելու համար։ Խմբավորված խմբագրումից առաջ ստուգեք կողպեքներն ու թիրախ թղթապանակը. մեծ կառուցվածքային փոփոխությունից առաջ պահպանեք [նկարապատկեր](/soundscaper/save-session-snapshots/)։
