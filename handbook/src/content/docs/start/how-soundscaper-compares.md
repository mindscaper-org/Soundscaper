Compare Soundscaper Web and Desktop with Audacity 4.0.2, Adobe Audition,
Ardour 9.10, Hindenburg Pro 2, Pro Tools Studio, ArtCraft SoundCraft 0.19.0
(pre-alpha), FL Studio 2026 All Plugins Edition, Ableton Live 12 Suite,
and Bitwig Studio 6.

## Reading the tables

- <span class="verdict verdict--yes" role="img" aria-label="Supported">+</span> Supported.
- <span class="verdict verdict--partial" role="img" aria-label="Limited">~</span> Partial or platform-dependent.
- <span class="verdict verdict--no" role="img" aria-label="Unavailable">/</span> Unavailable, external plug-in only, or absent from the reviewed sources.

Hover, focus, or tap an underlined cell for details. Ratings cover built-in
features; included first-party devices and packs count, while external plug-ins
do not. Plug-in hosting rows rate the host itself. Optional Soundscaper models
and engines are part of its built-in assistance workflow.

**Audio focus** and **MIDI focus** describe workflow emphasis on a spectrum.
Ardour and Pro Tools combine MIDI tools with a recording and mixing focus;
Live and Bitwig also record and edit audio. Shared header shading keeps related
editors together. Scroll horizontally to compare all products; capability names
stay visible.

and zoom shortcuts, and adds Page Up/Page Down timeline scrolling. It also fixes

**Pro Tools Studio and SoundCraft**

The tables compare the paid **Pro Tools Studio** tier with ArtCraft's
**SoundCraft 0.19.0**. Pro Tools also has Intro, Artist, and Ultimate tiers
with different limits. SoundCraft is a separate DAW from ArtCraft, not the
Soundcraft mixing-console brand. Its developers describe it as pre-alpha;
the capabilities below are documented, not verified here against running builds.
The SoundCraft column covers both its desktop and self-hosted browser builds
