Corta o inserta un pasaje en las pistas anidadas de una carpeta sin expandirlas todas.

## Antes de empezar

Crea una carpeta de pistas con **Menú de pista > Mover la selección a una nueva carpeta** o abre una organización de carpetas existente. Identifica la carpeta cuyo contenido debe moverse de forma conjunta.

## Pasos

1. Selecciona la carpeta contraída y elige **Editar > Edit folder contents > Select folder contents**. El mismo submenú está disponible en el menú contextual de la carpeta.
2. Arrastra un intervalo de tiempo en la vista general de la carpeta y comprueba el inicio y el final de la selección.
3. En **Cut from folder and close gap**, elige **Edit folder contents** para quitar el pasaje y desplazar el material posterior dentro de la carpeta.
4. Usa **Insert clipboard into folder** para insertar el material copiado o **Deshacer** para revertir la operación.

## Comprobar el resultado

La carpeta sigue contraída mientras se editan sus pistas descendientes. Después, expándela para inspeccionar los cortes y confirmar que las pistas ajenas a la carpeta siguen en su sitio.

## Límites y recuperación

Las ediciones de carpeta se limitan a las pistas descendientes, no a todo el proyecto automáticamente. Escucha la edición junto con música o ambiente externos para detectar diferencias de temporización que no sean intencionadas. Comprueba los bloqueos y la carpeta correcta antes de hacer una edición agrupada; guarda una [instantánea](/soundscaper/save-session-snapshots/) antes de un cambio estructural importante.
