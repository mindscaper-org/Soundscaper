Soundscaper es el editor especializado en audio. Combina menús y un modelo de edición alineados con Audacity con una bandeja de proyectos, organización multipista no destructiva, grabación, efectos en tiempo real, análisis de sonoridad y frecuencias e intercambio de proyectos portátiles.

## Recorrido recomendado

1. Sigue el tutorial [Tu primer proyecto de Soundscaper](/tutorials/your-first-project/).
2. [Configura la grabación](/soundscaper/recording/) si necesitas material nuevo.
3. [Edita, mezcla y exporta](/soundscaper/edit-mix-and-export/).
4. Consulta [el almacenamiento y las copias de seguridad](/projects-and-data/storage-backups-and-privacy/).
5. Elige una [guía práctica](/guides/) para tu tarea: reducción de ruido, fundidos, sonoridad, exportación y más.

Abre el editor web en [soundscaper.org/en](https://soundscaper.org/en/).

Para obtener ayuda con la versión de escritorio, consulta [procesamiento local, modelos y complementos](/help/local-processing/).

Para seguir o controlar otro transporte, consulta la [sincronización de código de tiempo](/soundscaper/timecode-synchronization/).
