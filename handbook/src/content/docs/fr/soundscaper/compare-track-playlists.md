Conservez plusieurs arrangements d’une même piste et passez de l’un à l’autre.

## Avant de commencer

Dans un projet Soundscaper modifiable, sélectionnez la piste audio à monter. Les listes de lecture changent le contenu de cette piste ; utilisez un [instantané de session](/soundscaper/save-session-snapshots/) pour conserver un arrangement entier.

## Étapes

1. Ouvrez **Menu des pistes > Track playlists**.
2. Saisissez un **Playlist name**, puis choisissez **Duplicate current playlist**. Modifiez cette copie active dans la timeline. Choisissez plutôt **Create empty playlist** si vous avez besoin d’une version vierge.
3. Rouvrez la boîte de dialogue, sélectionnez **Original** dans **Playlists**, puis choisissez **Activate playlist** pour écouter le montage précédent.
4. Activez la version alternative pour la comparer. Lorsque vous avez terminé, utilisez **Rename playlist** ou supprimez une liste inactive.

## Vérifier le résultat

Seule la liste de lecture active apparaît sur cette piste. **Annuler** inverse le changement. Attendez l’enregistrement du projet, rouvrez-le et vérifiez que les deux versions nommées sont toujours disponibles.

## Limites et récupération

La liste active ne peut pas être supprimée. Les versions inactives conservent l’audio auquel elles font référence et occupent de l’espace. Les listes de lecture sont des variantes d’une piste, et non des couches simultanées ; placez le contenu sur des pistes distinctes pour entendre les deux à la fois.
