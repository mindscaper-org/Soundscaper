Coupez ou insérez un passage dans les pistes imbriquées d’un dossier sans développer chaque piste.

## Avant de commencer

Créez un dossier de pistes à l’aide de **Menu de piste > Déplacer la sélection dans un nouveau dossier**, ou ouvrez un arrangement en dossier existant. Repérez le dossier dont le contenu doit être déplacé ensemble.

## Étapes

1. Sélectionnez le dossier réduit et choisissez **Édition > Edit folder contents > Select folder contents**. Le même sous-menu se trouve dans le menu contextuel du dossier.
2. Faites glisser pour définir une plage temporelle dans l’aperçu du dossier, puis vérifiez les heures de début et de fin.
3. Dans **Cut from folder and close gap**, choisissez **Edit folder contents** pour supprimer le passage et décaler le contenu suivant dans ce dossier.
4. Utilisez **Insert clipboard into folder** pour insérer du contenu copié, ou **Annuler** pour inverser l’opération.

## Vérifier le résultat

Le dossier reste réduit tandis que les pistes qu’il contient sont modifiées. Développez-le ensuite pour examiner les coupes et vérifier que les pistes extérieures au dossier sont restées en place.

## Limites et récupération

Les modifications du dossier s’appliquent à ses éléments descendants, pas automatiquement à tout le projet. Écoutez à la jonction avec la musique ou l’ambiance extérieure pour repérer les différences de synchronisation intentionnelles. Vérifiez les verrouillages et le dossier visé avant le montage groupé ; enregistrez un [instantané](/soundscaper/save-session-snapshots/) avant tout changement structurel important.
