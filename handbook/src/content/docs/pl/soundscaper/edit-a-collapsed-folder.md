Wytnij lub wstaw fragment w zagnieżdżonych ścieżkach folderu, nie rozwijając każdej ścieżki.

## Zanim zaczniesz

Utwórz folder ścieżek za pomocą **Menu ścieżki > Przenieś zaznaczenie do nowej folderu** albo otwórz istniejący układ folderów. Określ folder, którego zawartość ma się przesunąć razem.

## Kroki

1. Zaznacz zwinięty folder i wybierz **Edytuj > Edit folder contents > Select folder contents**. To samo podmenu jest dostępne w menu kontekstowym folderu.
2. Przeciągnij zakres czasu w podglądzie folderu i sprawdź początek oraz koniec zaznaczenia.
3. Wybierz **Cut from folder and close gap** z menu **Edit folder contents**, aby usunąć fragment i przesunąć późniejszy materiał w obrębie folderu.
4. Użyj **Insert clipboard into folder**, aby wstawić skopiowany materiał, albo **Cofnij**, aby cofnąć operację.

## Sprawdź wynik

Folder pozostaje zwinięty, a edycja obejmuje jego ścieżki potomne. Później rozwiń folder, aby obejrzeć cięcia i potwierdzić, że niezwiązane ścieżki poza nim pozostały na miejscu.

## Ograniczenia i odzyskiwanie

Edycje folderu obejmują jego potomków, a nie automatycznie cały projekt. Odsłuchaj edycję z muzyką lub tłem spoza folderu, aby wykryć niezamierzony różnicę czasu. Przed edycją grupową sprawdź blokady i wybrany folder; przed dużą zmianą strukturalną zapisz [migawkę](/soundscaper/save-session-snapshots/).
